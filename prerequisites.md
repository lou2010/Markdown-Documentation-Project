# Prerequisites 
## Creating an Account on GitHub
Before publishing files to GitHub, you need to create an account. This account will serve as the online location where your Markdown files and projects are stored.
Visit [GitHub](https://github.com) to begin creating an account. 
1.	Select **Sign up** and enter your email address.
2.	Create a username and password that meet GitHub’s requirements.
3.	Select **Create Account** to continue.
4.	Check your email for the verification message and follow the instructions to activate account.
5.	Sign in using your username or email address and password. 
**Note:** Keep your username and password in a safe location so that you can access your account later.
## Installing VS Code
VS Code is where you will create and edit your Markdown files. 
1.	Visit the [Visual Studio Code](https://code.visualstudio.com) website.
2.	Click on the button to download.
3.	After the download is finished, find the file in the Downloads folder.
4.	Open the installer and follow the installation instructions.
5.	Open VS Code to confirm that it installed successfully.
## Install Git Bash (Windows)
Git Bash is a command-line program that runs Git commands.  Git Bash lets you run the Git commands you'll use later in this guide to save and publish your Markdown files to GitHub
1.	Visit the [Git](https://git-scm.com/install/) website.
2.	Choose Windows as the operating system. 
3.	Download the version appropriate for your operating system.
4.	Once the download has finished, click the file to begin installation.
5.	Open Git Bash to confirm installation.

After finishing all of these downloads, you’re ready to create your first Markdown file.
