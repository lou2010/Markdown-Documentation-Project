# Creating a Markdown File
Now that you have the tools to create a Markdown file, here you will learn some Markdown syntax. By the end, you will make your own practice file so that you can then publish to GitHub.
## Creating a Markdown File in VS Code
1.	Open VS Code.
2.	Click File
3.	Select New.
Alternatively, the shortcut Ctrl+N will open a new file.
Before typing in your content, you should save the file you are working on in VS Code as a Markdown file. A Markdown file is identified in VS Code with the `.md` extension. That extension is important to have because you will be using Markdown syntax, which VS Code will interpret as a Markdown document so that it can translate onto GitHub.
1.	Click **File**.
2.	Click **Save As**.
3.	In **Save As dialog box**, click on the Save as Type drop down.
4.	Select  **Markdown**.
5.	Click **Save**.
## Markdown Basics.
So you can focus on the content you have to write, here are basic Markdown rules to follow when working on your file.
### Headings and paragraphs
One “#” indicates a level 1 heading. Each additional “#” is another level. For example:
```markdown
# This is a level 1 heading.		
## This is a level two heading.
```
will show up as 
# This is a level 1 heading.		
## This is a level two heading.
Notice that there is a space between the # and the text.
For paragraphs, there has to be a line break between one paragraph and another to separate each one.
### Lists
There are two types of lists to create in Markdown: ordered and unordered.
To create ordered lists, put either a number and a period or a parenthesis.

For example, this coded list 
```
1.	Snap
2.	Crackle
3.	Pop
```
produces this: 
1)	Snap
2)	Crackle
3)	Pop 

For unordered lists, use the following symbols before your items: asterisks (*), plus (+), or hyphens (-) to mark the list.

For example, this coded list
```
* Apples
* Oranges
* Kiwi
```
produces this:
* Apples
* Oranges
* Kiwi

Always put a space between the marker and the item.

### Links	
To add a link to your file, put the text of the link in brackets followed by the web address in parentheses.
In this example,
```markdown
Visit [Goodspeed’s website](https://www.goodspeed.org).
```
will show up as this 
Visit [Goodspeed’s website](https://www.goodspeed.org).
## Making a sample file
Now that you know how to create a Markdown file and have seen the basic syntax, make a practice file so that you understand the concepts. Please include the following pieces:
* A header
* A paragraph
* A list 
* A hyperlink

For this exercise, create a folder on your desktop or your Documents folder so that you can easily access it. That will be important when you get to the point of committing the file to GitHub. Once the file and folder are done, you can then learn about committing changes to Git.
