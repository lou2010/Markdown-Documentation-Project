# Overview
This guide will show how to create a Markdown file, save it in a GitHub  repository, and publish your changes using Git.
Markdown is a markup language where you can use simple elements to format a document such as a website. Even without a coding background, the system is straightforward. Check out the [Markdown guide](https://markdownguide.org) to learn more about what the basic syntax of Markdown. The tags used here will give you a basic overview of how it works.
Your Markdown files will be stored on GitHub, which hosts repositories and allows users to store, manage, and share projects. When creating a repository, you can choose whether it is public or private. If you are curious what this means if you are used to Word, think of GitHub as where you show the final published project. You will format the content using Markdown tags directly in the file.
## What You’ll Need
Before you can get started on writing and editing, you need a few programs on your computer:

* [Visual Studio Code]( https://code.visualstudio.com/) 
* [GitBash]( https://git-scm.com/install/)

Visual Studio Code is used to create and edit files like those written in Markdown.  Unlike writing the documents in Word, you have to write the tags in Markdown to format your document. Here is where you will write your content in Markdown that will go onto GitHub. 

Git Bash provides access to Git commands that allow you to track changes and publish files to GitHub. Think of this as the publishing tool for your content.  Whenever you have to track and publish changes, Git will be the place to go. The Git commands used here will not go beyond what you need to publish to GitHub. When you get comfortable with the commands here, please feel free to learn more as that knowledge will allow you to work with more developer-centered content. 

Be sure to choose the correct operating system for your computer. 

Once both are downloaded on your computer, you are ready to begin creating your files in Markdown.
