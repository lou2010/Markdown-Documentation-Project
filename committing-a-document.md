# Committing a Document
Now that the file has been staged, the next step involves pushing the commit onto the online GitHub repository.

1.	On the Git bash command line write `git status`.
2.	Confirm that the following line is there: `Changes to be committed`. The file name will be beneath. This is important to check that the file name being committed is correct.
3.	Write this on the command line: `git commit -m` followed by a message in quotations. For example: `git commit -m "This file has been changed."` This comment describes the changes recorded by the commit.
4.	Enter `git status` on the command line. A successful commit will show the following line: `nothing to commit, working tree clean`.
Now that your file has been committed, you are now ready for the most important step: pushing the commit online to GitHub.
