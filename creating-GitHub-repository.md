# Create a GitHub Repository
You need to create a GitHub repository so your content has a place to go on GitHub. A repository holds the files you have created for a project as it changes over time. We will create the actual connection in the next step. Having a repository set up is an important part to publishing on GitHub. When you finish these directions, you will have a GitHub repository that can hold your files.
1.	Log into your GitHub account, which will bring you to the dashboard.
2.	Click the button “New.”
3.	Choose a name for your repository. You may add a description, but that is not required.
4.	Choose whether the repository will be **Public** or **Private**. Private repositories will allow only certain collaborators to see your work while public repositories are open for everyone to see. 
5.	Do **not** choose to add a Readme, `.gitignore`, or license. These are not necessary as you will add the Markdown file you created in a later step.
6.	Click “Create Repository.”

Adding a description may also be helpful as it will tell visitors what the purpose of the repository is and what the visitor can expect to find. It might be good to choose a name that matches your practice folder so things are consistent and easy for you to locate. Once the repository has been set up, you can move toward making your first commit, bringing you closer to publishing on GitHub.
